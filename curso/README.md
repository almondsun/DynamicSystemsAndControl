# Material del curso

Material entregado por el profesor Juan David Bastidas Rodríguez en *Sistemas
Dinámicos y Control* (UNAL Manizales, 2026-2). Es la teoría con la que se modeló,
diseñó e implementó el convertidor Buck. Los derechos pertenecen a sus autores; se
conserva aquí solo como referencia de estudio.
